# plan.ai — Overview

plan.ai is building sovereign AI infrastructure: dedicated Apple Silicon hardware designed to run autonomous departments inside organizations.

## Core Proposition

- No required cloud dependency, no per-seat SaaS tax
- Sensitive work stays local by default with governed cloud escalation only when you choose
- One-time hardware investment that replaces ongoing SaaS spend over time

## What It Is

A pre-configured Apple Silicon node that becomes the cognitive backbone of an organization. It runs foundation models locally for low-latency inference, orchestrates autonomous agents in sandboxed execution, and builds persistent organizational memory that compounds over time.

## Key Differentiators

- **GDPR-first mindset**: Privacy is an engineering constraint, not an afterthought
- **EU AI Act-ready architecture**: Audit trails and governance built in
- **Local-first**: Data stays on your hardware by default
- **Hybrid intelligence**: Controlled cloud escalation when frontier-model reasoning is needed — only sanitized context reaches external models

## Design Principles

1. **Sovereign by default**: Your data infrastructure belongs to you
2. **Transparent by architecture**: Every workflow is auditable, every decision point visible
3. **Incremental by design**: Start with one department and one workflow
4. **European by conviction**: GDPR, EU AI Act, and privacy expectations treated as first-class engineering constraints

## Current Status

plan.ai is in active development. The core architecture exists and is being validated with early partners in real environments. Early access is available for interested organizations.
